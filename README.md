# Savage Demo

## A full-stack message board application that allows users to post messages and interact with them through voting and deletion.

## Features

- Create and display messages

- Thumbs-up voting

- Delete messages

- Update the interface after database changes

## Technologies Used

- Frontend: HTML, CSS, JavaScript, EJS

- Backend: Node.js, Express.js

- Database: MongoDB

## How It Works

- Users enter information into a message form.

- The browser sends a POST request to the Express server.

- The server stores the message in MongoDB.

- Stored messages are retrieved and rendered on the page.

- Fetch requests send PUT or DELETE requests to the appropriate server routes.

- The server updates or deletes the matching database record.


## Installation

- Clone repository 
- run npm install
